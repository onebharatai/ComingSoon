# RegRev - Coming Soon

A modern, glassmorphism-styled "Coming Soon" landing page for RegRev.

## Deployment

### Deploy to Vercel

1. **Install Vercel CLI** (if doing it from terminal):
   ```bash
   npm i -g vercel
   ```

2. **Deploy**:
   Run the following command in the project directory:
   ```bash
   vercel
   ```
   Follow the prompts to deploy.

   **OR**

   Connect your GitHub repository to [Vercel](https://vercel.com) and it will automatically detect the static site.

## Stack
- HTML5
- Tailwind CSS (via CDN)
